# VAKAPO · Podología bovina

App web para registrar la salud de las pezuñas de las vacas en el tambo, pensada para el celular y para trabajar sin señal.

- Diagrama de pezuña (vista caudal-plantar) con zonas ICAR tocables y dedos rudimentarios.
- Catálogo de lesiones ICAR editable, con gravedades propias de cada lesión.
- Jornadas por tambo, teclado numérico para el número de vaca, recorte preventivo con un toque.
- Productos y servicios con precios por tambo en guaraníes, recetas veterinarias, fotos.
- Historial por vaca, alertas de revisión y de vaca recurrente (solo administradores).
- Reportes: mapa de calor, prevalencia por lesión, por mes y por lote, costos; exportación PDF y Excel.
- Varios tambos separados; administradores (podólogo/veterinario) y propietarios (solo su tambo, solo notas).
- Guardado continuo en el equipo y sincronización con la nube cuando hay señal.
